Identifier et appliquer sa convention collective

Toute entreprise doit appliquer la convention collective correspondant à son activité (code NAF/APE). Elle fixe les minima de salaires, les conditions de travail, les régimes de prévoyance et mutuelle obligatoires. Le non-respect peut entraîner des redressements URSSAF.

Mis à jour : mai 2026 ● Source : legifrance.gouv.fr · Segment : Professionnels

Interlocuteur

🏭 URSSAF + Inspection du travail 📞 0 806 804 100 · Lun-Ven 8h-17h 🌐 legifrance.gouv.fr Accéder →

Délai estimé

⏱ Application immédiate dès la 1ère embauche

Documents nécessaires

  • Code NAF/APE de l'entreprise (sur le Kbis)
  • Convention collective identifiée
  • Grilles de salaires de la convention
  • Accords de branche applicables

    • Étapes de la démarche

    1. Identifier précisément la convention : Code NAF → legifrance.gouv.fr · plusieurs CC possibles si activités multiples
    2. Analyser les obligations : Salaires minima · préavis · indemnités · congés spéciaux · prévoyance · mutuelle
    3. Appliquer la mutuelle obligatoire : Depuis 2016 · contribution employeur >= 50%
    4. Prévoyance obligatoire : Certaines branches imposent une prévoyance · vérifier
    5. Grilles de classification : Coefficient ou niveau de chaque poste → salaire minimum de branche
    6. Veille sur les évolutions : Les accords de branche évoluent · veille ou cabinet de paie

    Conseils et points de vigilance

    Ne confondez pas convention collective et Code du travail. La convention peut être plus favorable pour le salarié (meilleures indemnités, congés supplémentaires) et dans ce cas elle s'applique. Elle ne peut jamais être moins favorable. En cas de doute, l'inspection du travail répond gratuitement.

    Erreurs fréquentes

    • Appliquer le SMIC au lieu des minima de branche (souvent supérieurs)
    • Oublier la mutuelle et prévoyance obligatoires
    • Ne pas mentionner la CC sur les bulletins de salaire
