Contester une amende (stationnement ou circulation)

Les amendes de stationnement (FPS) et de circulation (PV) peuvent être contestées via les voies de recours légales. Le Forfait Post-Stationnement (FPS) remplace le PV de stationnement depuis 2018. La contestation doit être faite dans les délais stricts, avec des motifs valables.

Mis à jour : mai 2026 ● Source : antai.gouv.fr · Segment : Particuliers

Interlocuteur

🏛️ ANTAI (amendes) + Officier du ministère public (OMP) + RAPO pour FPS 📞 34 00 · Lun-Ven 8h-18h 🌐 antai.gouv.fr Accéder →

Délai estimé

⏱️ PV : 45 jours · FPS stationnement : RAPO dans 1 mois · CCSP dans 3 mois

Documents nécessaires

  • Avis d'infraction ou avis de paiement
  • Pièce d'identité
  • Preuves à l'appui (photos, témoignages, justificatifs)
  • Justificatif de paiement si stationnement payant

    • Étapes de la démarche

    1. Analyser le motif de contestation — Infraction non commise · erreur sur l'immatriculation · véhicule vendu · force majeure · prescription
    2. PV circulation : recours sans payer — antai.gouv.fr → Contester une amende · NOR de l'avis · ne pas payer avant (le paiement vaut reconnaissance)
    3. FPS stationnement : RAPO — 1 mois pour le RAPO auprès de la collectivité · puis CCSP (Commission du Contentieux du Stationnement Payant) si rejet
    4. Rassembler les preuves — Photos horodatées · ticket de stationnement payé · certificat médical · témoignages
    5. Audience si nécessaire — Le tribunal de police statue · vous pouvez vous défendre sans avocat · le juge décide
    6. Décision et suite — Si contestation acceptée : amende annulée · si rejetée : payer dans les délais ou appel possible

    Conseils et points de vigilance

    Ne payez jamais une amende que vous souhaitez contester — le paiement vaut reconnaissance de l'infraction. Vous perdez alors tout droit à contester. Pour les FPS de stationnement, le RAPO est obligatoire avant toute saisine du CCSP. Documentez toujours vos motifs avec des preuves tangibles.

    Erreurs fréquentes

    • Payer l'amende avant de contester (reconnaissance implicite de l'infraction)
    • Dépasser le délai de contestation (45 jours pour les PV)
    • Oublier le RAPO obligatoire pour les FPS avant de saisir le CCSP
